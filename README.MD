# Проект Verstka

## Описание
Проект-макет магазина для продажи душераздирающих, но сомнительных товаров.\
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/Verstka.git
```
2. Установите зависимости:
```
poetry install
```
